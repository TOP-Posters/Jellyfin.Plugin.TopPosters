Logos and backgrounds must also be enabled in your TOP Posters dashboard. Enable TOP Posters as an image fetcher for each item type in your Jellyfin libraries, including Seasons.

Refresh existing artwork

Refresh replaces the selected artwork in libraries with TOP Posters enabled, including manually chosen images. Lock any items you want to keep. Metadata and watched progress are preserved.

Default: 100 titles per run. Each selected image uses an API request, even when unchanged. Large libraries rotate across runs, starting with titles checked least recently.

The task runs every 24 hours by default. Change its schedule or view progress under Dashboard → Scheduled Tasks → TOP Posters. After changing style or badges, use Save and refresh now to start the next batch.
